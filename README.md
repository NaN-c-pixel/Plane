# Multiverse Flight Control 🚀

A browser-based space exploration game with a spacecraft cockpit HUD, redesigned ship, zoomable starfield, sector scanner, autopilot, and 960 procedurally generated worlds across 12 galaxies.

## Play locally
Open `index.html` in a modern browser. No install or build step is required.

## Controls
- **W / ↑** — thrust
- **A / ←** and **D / →** — steer
- **Space** — boost
- **M** — toggle autopilot
- **Mouse wheel** or **ZOOM +/-** — zoom

Use **SCAN NEAREST** to select an undiscovered planet and engage autopilot. Discoveries are saved in your browser's local storage.

## Enable GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.

Once Pages finishes deploying, the game should be available at:
https://nan-c-pixel.github.io/Plane/
